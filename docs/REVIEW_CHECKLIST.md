# Review checklist

Use for PR review (self or peer). ~15 minutes.

1. Is the **intent** clear in one sentence?
2. Is **ATT&CK** mapping reasonable (or honestly unmapped)?
3. What is the biggest **false positive** risk?
4. Are **data sources** and adaptation needs clear?
5. Any **client-specific** or sensitive detail?
6. Would this **fail silently** if a log source disappeared?
7. Do file paths match the repo layout and coverage index?
